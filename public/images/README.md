# TAMED image assets

Place approved brand artwork here when available:

- `tamed-wordmark.svg` — official transparent wordmark for the site header/footer. Pass it to `Logo` with `imageSrc="/images/tamed-wordmark.svg"`; the current text wordmark remains the fallback.
- `tamed-favicon.ico` — a copy for asset handoff. Next.js serves the active app favicon from `src/app/favicon.ico`.
- `articles/` — locally stored article cover images referenced by `src/lib/imported-articles.json`.

No official TAMED logo artwork was supplied, so the site continues to display its editorial text wordmark until an approved logo is added.
